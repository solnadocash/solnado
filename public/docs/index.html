Solnado Documentation

What is Solnado?

Solnado is a privacy layer for Solana that enables private SOL transfers. Using zero-knowledge proofs and shielded pools, Solnado breaks the on-chain link between sender and recipient.

How It Works

When you send SOL privately through Solnado:

  • Step 1: Your SOL is deposited into a shielded pool
  • Step 2: A zero-knowledge proof is generated
  • Step 3: SOL is withdrawn to the recipient from the pool

The ZK proof ensures that only the amount is verified, not the connection between deposit and withdrawal. This breaks the on-chain link.

Privacy Model

Solnado uses the PrivacyCash protocol, which implements:

  • Shielded pool with Merkle tree commitments
  • Zero-knowledge proofs for withdrawal authorization
  • Nullifiers to prevent double-spending
  • Relayer for gas abstraction and additional privacy

Fees

A small relayer fee (currently 0.005 SOL) is deducted from each transfer. This covers gas costs and relayer operation.

Using Solnado

1. Connect Wallet

Click "Connect Wallet" and approve the connection in Phantom.

2. Enter Amount

Enter the amount of SOL you want to send (minimum 0.01 SOL).

3. Enter Recipient

Paste the recipient's Solana wallet address.

4. Send Privately

Click "Send privately" and sign the transaction in your wallet.

Technical Details

Solnado is built on:

  • PrivacyCash SDK - ZK proof generation
  • Solana blockchain - Fast, low-cost transactions
  • Cloudflare Tunnel - Secure, hidden infrastructure
